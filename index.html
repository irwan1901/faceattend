Integrasi REST API Google Apps Script & GitHub Pages

Agar pendaftaran Guru / Staf TU dan presensi wajah otomatis tersimpan di Google Spreadsheet Anda, masukkan URL Deployment Web App Google Apps Script berikut:

Cara Mendapatkan URL Web App:
  1. Buka file Code.gs di Google Apps Script Anda.
  2. Klik menu biru Deploy > New Deployment (Penerapan Baru).
  3. Pilih tipe Web App.
  4. Atur Execute as: Me dan Who has access: Anyone (Siapa saja).
  5. Klik Deploy lalu salin URL yang berakhiran /exec dan tempel di atas.
